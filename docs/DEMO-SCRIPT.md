# 5-minute demo script

Use two browser windows (or one normal and one private window) so you can switch between customer and admin quickly.

## 1. The customer's view (2 min)
1. Open the site → **Create one!** → make a customer account. A full-screen AgentSphere intro plays (click to skip).
2. On the dashboard, type **"Create change slip for Jordan Lee: add a surge protector $250"** and press Enter. The ChangeSlip form opens already filled in. Create the slip, then **Open customer page** → **Accept** to show the receipt and timeline.
3. Run **FormFirst** or **Nudge** from their cards: show the generated emails and the **Copy** buttons.
4. Run **OpenPing**: attach any small HTML/PDF file, then press **Customer opens link** to show the alert and the single follow-up draft. Click the bell to show the notification.
5. (With AI on) type **"Summarize the benefits of solar panels"** to show a Research Agent answer streaming in a result window.
6. Open an agent's **Download** to show the ZIP and the step-by-step Git guide.

## 2. The business flow (2 min)
1. As the customer: **Request custom agent** (bottom bar) → describe a need → send.
2. Switch to the admin window → sign in as **Admin** (`admin@agentsphere.com`). The Overview shows the new request.
3. **Quote requests → Accept request → Set price** (add a delivery time).
4. Back to the customer: the bell shows "Quote ready" → **Accept & pay** → use test card `4242 4242 4242 4242`.
5. Admin: **Payments** shows the payment and revenue. In **Quote requests** the job is Paid, so move it to **In progress → Delivered**.

## 3. Close (1 min)
- Admin **Payments → Edit options**: card/UPI/bank transfer, tax rate, bank details.
- **Settings**: change password, theme, API keys.
- Say clearly what is demo vs real (see README table) and what the production build needs.
